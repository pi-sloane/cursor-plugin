# Security policy

## Report a security issue

Please report suspected vulnerabilities in this Cursor plugin or Pi Security privately by emailing [contact@pi.security](mailto:contact@pi.security) with the subject **Security report: Cursor plugin**.

Include a short description, the potential impact, and steps to reproduce when available. Please keep vulnerability details out of public issues, discussions, and pull requests while we review the report.

Share only the sensitive information needed to investigate. If supporting material contains credentials, customer data, information from a Pi environment, private repository details, or non-public findings, mention that in your email so we can arrange an appropriate way to receive it.

If sensitive information has already been published, remove it where possible and rotate any exposed credentials before reporting the incident.

For product help and other non-security questions, email [contact@pi.security](mailto:contact@pi.security).
