# Contributing

Thanks for helping improve Pi Security for Cursor IDE.

## Contribution scope

We currently accept contributions only to the six skills under `skills/`. Other repository files are maintained by Pi Security.

## Skill changes

Keep each change focused on a clear user need. Preserve the skill's existing environment checks and confirmation steps, distinguish Pi evidence from interpretation, and keep read-only workflows read-only.

Use fictional names and identifiers in examples. Do not include credentials, customer data, private URLs, or other non-public information.

In your pull request, briefly describe the user need and how the skill addresses it.

For sensitive security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public pull request.
